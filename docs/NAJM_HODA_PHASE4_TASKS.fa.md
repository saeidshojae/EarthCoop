# ریزتسک های فاز 4 (خودگردانی مدیریتی سراسری)

## هدف
- تبدیل نجم هدا از اپراتور عملیات واکنشی به مدیر خودگردان سراسری با حلقه تصمیم گیری، اجرای ایمن، و نظارت انسانی.

## لیست تسک ها

1. `P4-T01` Autonomous Goal Loop Skeleton
- شرح: ایجاد حلقه دوره ای «دریافت هدف > تحلیل وضعیت > تولید برنامه اقدام» برای نجم هدا.
- خروجی: سرویس پایه loop با ثبت برنامه اقدام پیشنهادی در runtime.
- وابستگی: اتمام فاز 3
- وضعیت: `done`

2. `P4-T02` Capability Registry + Action Contracts
- شرح: تعریف رجیستری توانمندی ها و قرارداد ورودی/خروجی برای هر action قابل اجرا.
- خروجی: اجرای action فقط از طریق قراردادهای معتبر و قابل رهگیری.
- وابستگی: `P4-T01`
- وضعیت: `done`

3. `P4-T03` Safety Gate v2 (Policy + Budget + Scope)
- شرح: افزودن محدودیت سیاستی، بودجه مصرف منابع، و محدوده اثر قبل از هر اجرای خودکار.
- خروجی: بلوکه شدن خودکار اقدامات خارج از خط مشی.
- وابستگی: `P4-T02`
- وضعیت: `done`

4. `P4-T04` Human Escalation Workflow
- شرح: طراحی مسیر تایید انسانی برای اقدامات medium/high-risk و مسیر fallback.
- خروجی: صف تایید ادمین + SLA + ثبت علت تایید/رد.
- وابستگی: `P4-T03`
- وضعیت: `done`

5. `P4-T05` Cross-Module Observability Graph
- شرح: تجمیع سیگنال های چت، گروه، تکلیف، و خطاها در نمای یکپارچه تصمیم گیری.
- خروجی: context عملیاتی واحد برای تصمیم های نجم هدا.
- وابستگی: `P4-T01`
- وضعیت: `done`

6. `P4-T06` Proactive Recommendation Engine
- شرح: تولید پیشنهادهای فعالانه برای مشارکت کاربران/گروه ها بر اساس context و هدف.
- خروجی: توصیه های قابل توضیح با امتیاز اطمینان.
- وابستگی: `P4-T05`
- وضعیت: `done`

7. `P4-T07` Operator Action Executor v2
- شرح: اجرای خودکار اقدامات low-risk از برنامه اقدام با retry/cooldown/idempotency.
- خروجی: اجرای قابل اتکا بدون تکرار ناخواسته.
- وابستگی: `P4-T02`, `P4-T03`
- وضعیت: `done`

8. `P4-T08` Admin Control Surface (Pause/Resume/Override)
- شرح: افزودن کنترل پنل مدیریتی برای توقف، ادامه، و override سیاست ها.
- خروجی: کنترل کامل انسانی روی خودگردانی.
- وابستگی: `P4-T04`, `P4-T07`
- وضعیت: `done`

9. `P4-T09` Audit Narrative + Replayability
- شرح: ثبت روایت تصمیم تا اجرا (decision trace) و امکان بازپخش سناریو.
- خروجی: شفافیت عملیاتی و قابلیت ممیزی دقیق.
- وابستگی: `P4-T07`
- وضعیت: `done`

10. `P4-T10` Reliability Test Matrix + Chaos Scenarios
- شرح: تست های E2E و سناریوهای اختلال برای اطمینان از رفتار ایمن در خطا.
- خروجی: معیار پذیرش پایدار برای استقرار خودگردانی.
- وابستگی: `P4-T01` تا `P4-T09`
- وضعیت: `done`
