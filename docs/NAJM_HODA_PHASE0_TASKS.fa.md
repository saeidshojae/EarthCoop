# ریزتسک های فاز 0 (مقدمات)

## هدف
- ایجاد پایه قابل اعتماد برای شروع اتوماسیون نجم هدا.

## لیست تسک ها

1. `P0-T01` Enforce Feature Flag
- شرح: اعمال `NAJM_HODA_ENABLED` روی API, Listener, Command, Admin Chat
- خروجی: مسیرهای اصلی در حالت disabled اجرای AI نداشته باشند
- وابستگی: ندارد
- وضعیت: `done`

2. `P0-T02` پاسخ استاندارد disabled
- شرح: تعریف پیام/کد استاندارد (`NAJM_HODA_DISABLED`)
- خروجی: رفتار یکنواخت در endpointها
- وابستگی: `P0-T01`
- وضعیت: `done`

3. `P0-T03` پاکسازی mojibake در تنظیمات و متن های سیستمی
- شرح: اصلاح encoding در فایل های پیکربندی و promptها
- خروجی: خوانایی کامل فارسی در UI/log/config
- وابستگی: ندارد
- وضعیت: `done`

4. `P0-T04` تثبیت runtime config برای Auto-Fixer
- شرح: حذف تکیه بر cache برای تنظیمات حساس و استفاده از منبع پایدار
- خروجی: رفتار قابل پیش بینی در restart/deploy
- وابستگی: ندارد
- وضعیت: `done`

5. `P0-T05` لاگ حسابرسی برای blocked execution
- شرح: ثبت لاگ صریح زمانی که مسیرها به علت disabled متوقف می شوند
- خروجی: شفافیت عملیاتی
- وابستگی: `P0-T01`
- وضعیت: `done`

6. `P0-T06` تست مسیرهای کلیدی
- شرح: تست smoke برای API/Listener/Command با حالت enabled و disabled
- خروجی: جلوگیری از regression
- وابستگی: `P0-T01`, `P0-T02`
- وضعیت: `done`

## معیار اتمام فاز 0
- هیچ مسیر اصلی نجم هدا خارج از کنترل `NAJM_HODA_ENABLED` نباشد.
- encoding شکسته در فایل های هسته ای نجم هدا وجود نداشته باشد.
- تنظیمات حساس runtime پایدار باشند.
- تست smoke پایه پاس شود.
