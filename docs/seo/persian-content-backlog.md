Status: prioritized recommendation for Phase 2 (Pillars) and Phase 3 (blog). This document selects canonical topic ownership; it does not publish content by itself.

## Selection principles

The first wave prioritizes concepts that satisfy all of these conditions:

1. high EarthCoop fit;
2. stable core definition;
3. meaningful Persian discovery intent or strong proprietary entity-building value;
4. enough conceptual depth for a useful page;
5. low risk of inaccurate equivalence with external models;
6. clear distinction from neighboring target URLs.

Broad head terms are not given standalone pages merely because they are important. A Pillar must own a coherent intent cluster and explain a distinctive EarthCoop relationship.

## Canonical ownership rules

- `/` owns the **brand/overview intent** for `EarthCoop` and `ارثکوپ`. Do not create a competing `/earthcoop/` page in the first wave.
- One cluster has one primary target URL.
- Supporting articles target narrower questions/comparisons and link upward to the Pillar.
- The Docs Center is the formal/legal evidence layer; Pillars summarize and explain rather than duplicating entire legal documents.
- Proprietary concepts with evolving parameters may be explained only at stable-core level.

## `بهار` → candidate `/economy/bahar/`

Reason: internal monetary-unit identity is stable, but creation/activation/valuation/contractual details remain evolving. Entity-building article/page comes after a publication-safe claim matrix is frozen.

## `اقتصاد مردمی` → candidate `/economy/people/`

Reason: useful and high-fit, but first-wave `/economy/` can own both the proprietary model and generic bridge without creating immediate cannibalization. Split only if content depth and Search Console demand justify it.

Reason: valuable cluster, but exact relationship to external crowdfunding/securities vocabulary requires product/legal terminology to be frozen first.

# Content quality contract

Every new Pillar/article must:

- answer the user's generic question before promoting EarthCoop;
- distinguish established external definitions from EarthCoop-specific definitions;
- cite authoritative external sources for generic claims when needed;
- cite/link official EarthCoop Docs for EarthCoop-specific formal claims;
- label comparison concepts accurately rather than using them as synonyms;
- avoid unsupported statistics and generated examples presented as facts;
- include a clear semantic purpose and parent Pillar;
- avoid duplicate intent already owned by another URL;
- use standard Persian for a worldwide Persian-speaking audience.

## Review gate for Phase 2

Before implementation, each selected Pillar must have a short content brief containing:

`target URL | primary intent | primary/secondary queries | exact EarthCoop claims | external concepts to define | prohibited equivalences | source docs | supporting articles | internal links | proposed title/H1/description`

Phase 2 should implement the Pillar infrastructure and the selected first set, not every deferred URL.
