# EarthCoop Persian SEO Internal Linking Map

Date: 2026-10-05

Purpose: define how main-site Pillars, blog articles and formal Docs reinforce one another without duplicating intent or legal text.

## Core linking rule

The default path is:

`Home / parent hub → Pillar → supporting article → relevant official Docs`

Natural reverse links are encouraged where useful:

- supporting articles link back to the owning Pillar;
- Pillars surface a small curated set of supporting articles;
- main-site explanatory pages link to formal Docs for authoritative rules;
- Docs remain the formal source and should not be rewritten merely for SEO.

Every supporting article must have **one primary Pillar owner** even when it cross-links to neighboring Pillars.

## Article template linking contract

Every new blog article should contain, where naturally relevant:

1. one contextual link to its owning Pillar within the article body;
2. zero to two cross-cluster links where they genuinely help the reader;
3. at least one official Docs reference when making an EarthCoop-specific formal claim;
4. no footer-like block of repetitive keyword anchors solely for SEO;
5. descriptive Persian anchor text matching the destination concept without exact-match repetition everywhere.

## Pillar template linking contract

Every Pillar should contain:

- parent/hub navigation where applicable;
- curated links to 3–6 high-value supporting articles, not an unbounded dump;
- a clearly marked «اسناد و منابع رسمی EarthCoop» section for relevant Docs;
- links to adjacent Pillars only where the conceptual boundary is explained.

## Cannibalization safeguards

- Article titles may contain a Pillar's keyword only when their intent is narrower/question-specific.
- Do not create a blog article titled exactly the same as the Pillar unless the Pillar itself is implemented through the blog system by design.
- If Search Console later shows two EarthCoop URLs competing for the same query cluster, review intent/content before changing canonical tags; prefer consolidating editorial scope and internal links over masking duplication with canonical hacks.
