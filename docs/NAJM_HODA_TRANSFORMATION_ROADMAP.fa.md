# نقشه راه تحول نجم هدا

## هدف نهایی
- نجم هدا به عنوان لایه هوشمند سراسری پروژه عمل کند.
- دستیار شخصی کاربران باشد و در چارچوب مجوزها اقدام عملی انجام دهد.
- مدیر خودکار سیستم باشد و عملیات روزمره را با ایمنی و حسابرسی کامل اجرا کند.

## اصول اجرا
- هیچ اقدام حساس بدون سیاست، لاگ حسابرسی، و امکان بازگشت انجام نشود.
- تصمیم‌های AI باید قابل توضیح و قابل ردگیری باشند.
- همه مسیرهای اجرا باید زیر کنترل Feature Flag مرکزی باشند.

## فازها

### فاز 0: کنترل، ایمنی، و آماده سازی (2 هفته)
- Enforce واقعی `NAJM_HODA_ENABLED` روی API/Listener/Command.
- حذف رفتارهای نمایشی در مسیرهای حساس (به ویژه Auto-Fixer settings/runtime).
- استانداردسازی encoding و حذف mojibake در config/prompt/log.
- تعریف سطح اختیار اقدام: `read-only`, `suggest`, `execute-low-risk`, `execute-high-risk`.
- خروجی: سیستم قابل خاموش/روشن شدن کامل، با ردگیری شفاف.

### فاز 1: Event Bus و Context (4 هفته)
- قرارداد رویدادها برای بخش‌های اصلی سیستم.
- جمع آوری context کاربر/گروه/سیستم برای تصمیم گیری.
- Trace استاندارد برای هر تصمیم/اقدام.
- خروجی: نجم هدا دید سراسری و داده ساخت یافته برای تصمیم گیری دارد.

### فاز 2: Copilot کاربر + اجرای اقدام (4 هفته)
- خروج از محدودیت steward-only با RBAC و Policy.
- اجرای امن سناریوهای واقعی مشارکت کاربر.
- حافظه کوتاه/بلندمدت کاربر و گروه با scope مشخص.
- خروجی: دستیار قابل اتکا برای همراهی و اقدام در سطح کاربر.

### فاز 3: مدیریت خودکار عملیات (4 هفته)
- پایش سلامت سیستم و triage خودکار خطا/تیکت.
- اجرای playbookهای کم ریسک به صورت زمان بندی شده.
- خروجی: کاهش بار عملیاتی دستی و کاهش MTTR.

### فاز 4: CodeOps خودکار کنترل شده (4 هفته)
- اسکن ترکیبی کد (Rule + AI) و تولید PR برای اصلاحات کم ریسک.
- Gate تست/امنیت قبل از merge و rollout.
- خروجی: بهبود مستمر کد بدون ریسک استقرار بی کنترل.

### فاز 5: Governance و Hardening (2 تا 4 هفته)
- داشبورد حکمرانی تصمیم ها، هزینه AI، و شاخص های کیفی.
- تمرین سناریوهای بحران، runbook، و fail-safe.
- خروجی: آمادگی بهره برداری پایدار 24/7.

## شاخص های موفقیت
- نرخ موفقیت اقدام خودکار >= 95%
- سهم عملیات روزمره خودکار >= 60%
- کاهش MTTR >= 30%
- rollback ناخواسته < 2%
- رضایت کاربر >= 80%

## وضعیت شروع
- این سند مبنای اجرایی است.
- اجرای عملی از فاز 0 آغاز می شود.
